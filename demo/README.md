# DiagDiscover product demonstration

- [Watch or download the 1080p film](DiagDiscover-Product-Film-1080p.mp4?raw=true)
- [English captions](DiagDiscover-English.srt)
- [Narration transcript](Narration-script.txt)

The film is **4 minutes 21 seconds**, with English narration, burned-in
captions, animated explanations, actual application captures and original
ambient background music. The MP4 contains both picture and sound. If GitHub
does not play it inline, download it and open it in a normal video player.

The film demonstrates the signed catalogue, successful diagnostic invocation,
live health measurements, tampered DNS rejection, signed-but-invalid metadata,
and denial of an incorrect service token. Captured readings are snapshots from
the recorded local demonstration, not current measurements of an evaluator's
machine. Latency and traceroute return explicitly labelled sample responses.

This is a recorded demonstration of a local prototype. To run it yourself, use
the [project setup instructions](../README.md) and
[evaluation walkthrough](../docs/EVALUATION.md). There is no public hosted
diagnostic endpoint; the complete runnable source and Windows deliverable are
provided directly in the repository.
